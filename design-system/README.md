# design-system/

The Inzivo brand & design system, sourced from the shipped "Inzivo Redesign"
mobile theme. Start with [BRAND.md](BRAND.md).

- [BRAND.md](BRAND.md) — brand guidelines: identity, color, typography, spacing, radius, button rules, do/don't
- [tokens.json](tokens.json) — raw tokens, language-agnostic
- [tokens.css](tokens.css) — CSS custom properties for the web app
- [tokens.ts](tokens.ts) — TypeScript module
- [logo.svg](logo.svg) — static Z-gate mark
- [components/reference.html](components/reference.html) — open in a browser for a live visual reference (buttons, cards, badges, inputs, type scale, color swatches)
